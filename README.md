# Проект "Проект "«Объектно-ориентированное программирование"

## Описание:

В этом проекте мы начнем с описания основных сущностей и инициализации объектов.

## Установка:

1. Клонируйте репозиторий:
```
git clone git@github.com/evgeniya-avksenteva/Homework_OOP
```

2. Перейдите в директорию проекта:
```
Homework_OOP
```

3. Установите зависимости:
```
pip install -r requirements.txt
```

## Использование:

Точкой запуска программы является модуль main.py


Функционал:

В проекте реализованы следующие модули:

В модуле Сlasses.py - Созданы классы Product и Category, по которым описаны необходимые атрибутыю
Для класса Category добавлены два атрибута класса: количество категорий (category_count) 
и количество товаров (product_count).
Атрибуты класса заполняются автоматически при инициализации нового объекта.

Модуль main - является точкой запуска программы
