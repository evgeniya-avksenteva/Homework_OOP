# Проект "Проект "«Объектно-ориентированное программирование"

## Описание:

В этом проекте мы начнем с описания основных сущностей и инициализации объектов.

## Установка:

1. Клонируйте репозиторий:
```
git clone git@github.com/evgeniya-avksenteva/Homework_OOP
```

2. Перейдите в директорию проекта:
```
Homework_OOP
```

3. Установите зависимости:
```
pip install -r requirements.txt
```

## Использование:

Точкой запуска программы является модуль main.py


Функционал:

В проекте реализовано следующее:

- В модулях class_category.py и class_lawngrass.py- cозданы классы Category и Product соответственно,
по данным классам описаны необходимые атрибуты
- Для класса Category добавлены два атрибута класса: количество категорий (category_count) 
и количество товаров (product_count).
- Атрибуты класса заполняются автоматически при инициализации нового объекта.
- Добавлена инициализация
- Изменен тип атрибута с продуктами на приватный.
- Добавлен геттер для класса Category для вывода товаров.
- Добавлен класс-метод для создания нового товара.
- Реализован геттер и сеттер для цены товара.
- Для классов Category и продукта реализовали методы str.
- Для класса Product реализовали метод add.
- Выделены две категории товаров и созданы под них классы - оба класса являются
классами-наследниками от исходного класса Product.
- Доработана функциональность сложения таким образом, чтобы можно было складывать товары 
только из одинаковых классов продуктов.
- Доработан метод, который добавляет продукт в категорию, таким образом, чтобы не было возможности 
добавить вместо продукта или его наследников любой другой объект.

Модуль main - является точкой запуска программы
